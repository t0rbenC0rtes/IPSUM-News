# IPSUM News

## Overview
IPSUM News is a landing page project created as a direct copy of a Figma design. The project focuses on accurately replicating the visual design while incorporating smooth animations to enhance user experience.

## Tech Stack
- **HTML**
- **CSS**

## Project Goal
The goal of this project is to:
1. Recreate a Figma design as a fully responsive landing page.
2. Implement engaging animations to elevate the design's interactivity.
3. Practice precision in design-to-code conversion while adhering to modern web standards.

## Features
- Pixel-perfect replication of the Figma layout.
- CSS-based animations for a dynamic and engaging user experience.

Feel free to use this project to practice or adapt the design for your own purposes!
